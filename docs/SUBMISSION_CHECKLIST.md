## Prepare the documents

1. Open each Word report in Google Docs and replace `[Your name]`. Each report already includes its evaluation and repository link.
2. Review the known limitations: Week 2 retains one unsupported criterion statement; Week 3 has no measured manual time baseline.
3. Use the appropriate public GitHub link for each week's code submission. No repository invitation is needed.

Both apps run locally. The READMEs explain Python 3.12 setup and configuring the reviewer's own Nebius key. Week 3 state persists locally across restarts; approval remains required before the final save. No course submission has been made on your behalf.
